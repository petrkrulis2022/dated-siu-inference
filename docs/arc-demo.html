Run the trade

    
Triggers the whole loop in one call: the buyer asks
      both sellers for a quote, picks whichever is cheaper in SIU, locks USDC in the
      TouchstoneEscrow contract, waits for that seller to run real inference and
      settle for its real metered cost, then independently verifies the payment through the MCP
      server. Takes roughly 60–150 real seconds — it's waiting on live inference and live chain
      confirmations, not stalled.
