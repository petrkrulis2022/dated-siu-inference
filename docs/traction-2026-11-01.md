# Touchstone Assay: traction as of 1 November 2026

Touchstone Assay publishes **Dated SIU**, a daily benchmark price for AI inference work. It is measured by actually buying inference from a fixed set of models, grading the results with objective checks, and publishing the cost of one standard basket of work as a signed print.

Every figure below comes from our own stored records: the prints in this repository, our CI runs, our server's usage and settlement logs, and public block explorers. Where the records do not hold a number, it says so. Nothing is estimated. **Everything on-chain is on testnet so far, and the project is pre-revenue.**

## 2. The paid MCP server

Agents reach the index through a four-tool MCP server at `mcp.touchstoneassay.com`. Reading the index (`get_index`) is free. Quotes, conversions and receipt checks are paid per call in stablecoins through x402. Payments settle on Base Sepolia, Arc Testnet and Kite testnet; mainnet is built but not switched on.

| Calls logged, 25 Aug to 1 Nov 2026                                         | Count | Who                                                         |
| -------------------------------------------------------------------------- | ----- | ----------------------------------------------------------- |
| `get_index` (free)                                                         | 146   | **Unknown**: free calls record no caller, by design         |
| Paid calls (`get_quote` 14, `convert` 6, `verify_receipt` 8)               | 28    | **All ours**: our own test wallet, testing the payment path |
| Paid calls from outside wallets                                            | **0** | none                                                        |
| Automated outside probes calling non-existent tools (two scanner services) | 64    | outside, not use of the product                             |

**No external users yet.** Nothing settled in real USDC: the 28 paid calls settled small amounts of test tokens on testnets only.

## 3. The Blockworks trial

Since 17 October 2026 we have measured what it costs AI agents to do crypto research on Blockworks' licensed data. The trial is extended to 6 November.

- **The tasks:** perp DEX volume share, lending protocol P&L, token unlock overhang and stablecoin supply moves. Each is generated fresh every day and checked against an answer key computed from the same data.
- **Two modes:** the agents answer either from a stored daily snapshot, or by finding and pulling the data themselves through Blockworks' own MCP server.
- **What is recorded:** pass or fail, billed cost, and how the agent used the tools.
- **Reporting:** the results go to Blockworks first, as a findings report at the end of the trial, so they are not published here.
